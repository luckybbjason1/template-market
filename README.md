# Template Market
# 自动赚钱的模板销售平台

## 快速部署

### Gumroad (推荐)
1. 访问 https://gumroad.com/
2. 创建账号
3. 点击 "Create a product"
4. 选择 "Digital product"
5. 上传模板文件
6. 设置价格
7. 发布

### 本地运行
```bash
cd ~/桌面/template-market
pip install fastapi uvicorn
uvicorn main:app --port 8001
```
